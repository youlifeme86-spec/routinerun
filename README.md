# 루틴런 (초등)

초등 3~6학년 학습 루틴 코칭 서비스 **루틴런** 홈페이지입니다.
매일 공부를 체크하고, 동물 캐릭터와 레이스를 달리며 공부 습관을 키워요.

- 홈: `index.html`
- 레이스 보드: `race.html`
- 학생 존: `student.html`
- 학부모 리포트: `parent.html`
- 이용 안내: `guide.html`
- 선생님 전용(관리자): `admin.html` — 관리자 비밀번호로 들어가요.

데이터와 앱 화면은 Google Apps Script 웹앱에서 불러와요.
웹앱 배포 주소가 바뀌면 `site.js` 맨 위 `APP` 한 줄만 고치면 됩니다.
